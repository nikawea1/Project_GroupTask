# GroupTask

Десктопное приложение для управления персональными и групповыми задачами: интерактивный планер, канбан-статусы, аналитика с диаграммами, админ-панель и выгрузка отчётов. Написано на C++ Builder, данные хранятся в базе Microsoft Access.

## Основные возможности

**Планер и задачи**
- список задач в таблице с сортировкой, фильтрацией по категориям и статусам
- поиск задач по первым буквам названия
- интерактивный список задач на сегодня с отметками выполнения
- добавление, редактирование и удаление задач
- таймер с отслеживанием дедлайнов

**Групповые задачи**
- поддержка командной работы: создание групп и распределение участников
- общие групповые задачи с уникальными кодами проектов

**Аналитика и графики**
- модуль статистики с ручной отрисовкой столбчатых диаграмм на холсте (Canvas)
- пастельная цветовая дифференциация по статусам («выполнено», «в планах», «в процессе», «просрочено»)
- прогресс-бары выполнения и счётчики задач

**Журнал и отчёты**
- календарный фильтр задач по дате через DateTimePicker
- сводная статистика по выполненным и просроченным задачам
- автоматическая выгрузка отчётов через OLE Automation в форматы Word, Excel и текстовый файл

**Персонализация и безопасность**
- регистрация и авторизация с валидацией логина и пароля
- разделение прав: администратор видит задачи всех пользователей, сотрудник — только свои
- смена пароля текущего пользователя и удаление аккаунта
- выбор цветовых тем оформления и режимов подсветки строк таблицы


## Структура проекта

```text
Unit1.cpp / .h / .dfm   главное окно: планер, таблица задач, фильтры и темы
Unit2.cpp / .h / .dfm   форма авторизации и проверка прав доступа
Unit3.cpp / .h / .dfm   форма регистрации новых пользователей
Unit4.cpp / .h / .dfm   модуль аналитики: построение диаграмм и графиков
Unit5.cpp / .h / .dfm   окно сведений о задаче и программе
Unit6.cpp / .h / .dfm   журнал отчётов: выгрузка в Word, Excel и TXT
Unit7.cpp / .h / .dfm   настройки: темы оформления и личный кабинет
DbConfig.h              динамическое определение пути к базе данных
Project1.cbproj         файл проекта C++ Builder
планер_задач_пробник.mdb база данных Access
```

## Как запустить

Нужны Windows 10/11 и RAD Studio с C++ Builder. Для экспорта отчётов ещё нужен установленный Microsoft Office. Открыть Project1.cbproj в RAD Studio и запустить.

## Тестовые аккаунты

| Логин | Пароль | Роль | Описание |
|---|---|---|---|
| `admin` | `11` | администратор | полный доступ ко всем пользователям и задачам |
| `employee` | `1111` | сотрудник | планер, персональные и групповые задачи |
| `user1` | `1111` | сотрудник | тестовый пользователь |
